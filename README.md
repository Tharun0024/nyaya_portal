# Nyaya_Portal

**AI for Legal Assistance & Access**

Nyaya_Portal analyzes legal documents for information only. It is not a lawyer and does not provide legal advice. Findings include source quotes that are checked independently against the PDF text layer, rather than relying on the model to certify its own evidence.

## How It Works

1. Upload a PDF (up to 3 MB) or open the prepared demo.
2. Select a role and primary concern.
3. The server validates the PDF and renders its pages to JPEG images for NVIDIA NIM. The selected model does not accept raw PDF input.
4. NIM returns JSON-mode output. The server applies the existing Ajv schema validation and one repair attempt; invalid output fails closed.
5. In the browser, PDF.js extracts text and the deterministic evidence matcher classifies each source quote and maps matching text to PDF locations.
6. Review findings, uncertainty notes, evidence status, and questions to raise with a qualified professional.

The application has no database or session persistence. The PDF and analysis are held in memory for the current workflow. Live analysis sends document page images to the configured NVIDIA NIM endpoint; provider-side retention is governed by that service and is not controlled or guaranteed by this application.

## NVIDIA NIM Configuration

Configure these variables in the server environment only. Never use a `VITE_` prefix for credentials.

- `NVIDIA_API_KEY` (required for live analysis)
- `NIM_BASE_URL` (for example, `https://integrate.api.nvidia.com/v1`)
- `NIM_MODEL` (for example, `nvidia/Nemotron-3-Nano-Omni-30B-A3B-Reasoning-NVFP4`)
- `ALLOWED_ORIGIN` (optional; production CORS origin, defaults to `*` if unset)
- `USE_MOCK_NIM` (optional; set to `true` to force mock API responses)

Start the Vite frontend with `npm run dev`. Demo mode works without NIM credentials. Live local analysis requires a serverless-function runtime for `api/analyze.ts`; the Vite server alone does not run that function. Production deployment is configured for Vercel.

## Development

```bash
npm install
npm run dev
npm test
npm run typecheck
npm run lint
npm run build
```

Live validation is opt-in and requires explicit configuration plus `--live`:

```bash
npm run validate:live
npm run validate:smoke
```

Fixtures generated by `npm run generate:fixtures` are synthetic. Validation reports are written under `scripts/results/` and may contain fixture analysis; do not use real sensitive documents for those runs.

## Architecture

- Frontend: Vite, React, and TypeScript.
- Server: one stateless Vercel function at `POST /api/analyze`.
- Provider: NVIDIA NIM OpenAI-compatible chat completions with inline image inputs and JSON mode. The selected model does not support JSON Schema constrained decoding; server-side Ajv remains authoritative.
- PDF: PDF.js rasterizes pages on the server for NIM and independently extracts text in the browser for evidence matching and highlighting.
- State: React memory plus in-memory caches only; no database, cookies, localStorage, or sessionStorage.
